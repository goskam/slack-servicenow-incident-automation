slack-servicenow-incident-automation

A Slack bot that helps you raise and track ServiceNow tickets from your workspace.

## Status

- Slack bot is working and connected to Slack via Socket Mode
- It can receive messages and mentions
- Basic event handling is in place

## Next

- Add Ollama to understand user requests (like VPN issues or password resets)
- Connect ServiceNow to create tickets automatically
- Improve logic for routing different types of requests
